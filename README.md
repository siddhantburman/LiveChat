# LiveChat – Real-Time Chat Application

LiveChat is a modern web-based messaging application designed to make communication simple, fast, and user-friendly. It allows users to create accounts, log in securely, search for other users, start conversations, and manage their profiles.

The application features a clean and responsive interface with a chat sidebar, recent conversations, user search, and account settings. It uses React for the frontend, Tailwind CSS for styling, React Router for navigation, and REST APIs for backend communication.

### Key Features
- User Registration and Login
- User Search Functionality
- One-to-One Chat Creation
- Recent Chats Management
- User Profile Management
- Password Reset Functionality
- Responsive User Interface
- JWT Bearer Token-Based API Authentication

### Technology Stack
- **Frontend:** React.js, JavaScript
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Icons:** React Icons, Lucide React
- **Notifications:** React Toastify
- **API Communication:** Fetch API, REST APIs
- **Authentication:** JWT Bearer Token

### Project Objective
To develop a user-friendly messaging platform that provides a simple and organized communication experience through a modern web interface.
